# Light

Clean light appearance theme for UEFN Ducky — soft surfaces, blue accent.

Desktop plugin for [UEFN-Ducky](https://github.com/UEFN-Ducky/UEFN-Ducky) (`light`).
Install or update from **Settings → Store** in the app — do not install from a zip by hand.

## Build

```bash
py scripts/build_zip.py
```

Writes `deploy/light-1.0.8.ducky-plugin.zip` (scripts/ and deploy/ are not packed).
